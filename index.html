Finanzas

Finanzas es una aplicación personal de escritorio para llevar el control de mis finanzas. No es un servicio público ni se distribuye a otras personas.

Política de privacidad

Última actualización: 13 de octubre de 2026.

Qué datos de Google usa

  • Gmail (solo lectura): busca los correos con recibos de nómina (CFDI en XML y PDF) para registrar el ingreso, las deducciones y el neto. No envía, borra ni modifica correos.
  • Google Calendar: lee y crea eventos para mostrarlos en el calendario de la app.
  • Google Tasks: lee y crea tareas para mostrarlas en la app.
  • Google Drive: solo accede a los archivos que la propia app crea, para respaldar documentos.

Dónde se guardan los datos

Toda la información se guarda en una base de datos local en mi computadora. Las credenciales de acceso a Google se guardan cifradas con el sistema operativo. La app no tiene servidores propios.

Con quién se comparten

Con nadie. Los datos no se venden, no se comparten con terceros y no se usan para publicidad. El uso de la información recibida de las APIs de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions o con el botón "Desconectar" dentro de la app.
